# StatPanda 🐼

StatPanda is a lightweight, client-side web application designed to help users calculate and visualize basic statistical measures from datasets. The app requires no backend and runs entirely in the browser using vanilla JavaScript, HTML, and CSS (with Bootstrap 5).

## 🌟 Current Features

1. **Univariate Data Analysis**
   - **Frequency Distributions:** Analyze raw or grouped frequency intervals. View relative frequencies and cumulative frequencies.
   - **Measures of Central Tendency:** Calculate the Mean, Median, and Mode for your datasets.
   - **Measures of Variation:** Calculate Variance, Standard Deviation, and visualize data dispersion ranges.

2. **Data Ingestion Methods**
   - **Manual Entry:** Add samples one by one or declare group/N amounts.
   - **File Uploads:** Upload raw dataset representations using `.txt` files.
   - **Memory Management:** Seamlessly load or save current datasets using browser memory to easily move between application views.

3. **Data Visualizations & Reports**
   - **Extensive Charting:** Render graphical outputs via Bar, Line, Pie, Doughnut, Polar, and Radar charts through **Chart.js**.
   - **Specialized Plots:** View Histograms and Boxplots depending on the measure being analyzed.
   - **PDF Reports:** Download statistics tables and associated charts instantly formatted into a PDF file via **jsPDF**.

## 🛠️ Technologies Used

- HTML5 & Custom CSS
- Bootstrap 5 (with Dark/Light Theme Switching)
- FontAwesome 6
- Vanilla ES6 JavaScript Modules
- **Chart.js** (v4.5.0)
- **jsPDF** & **jsPDF-AutoTable**

## 🚀 Getting Started

Because StatPanda is completely client-side and vanilla JS, there's no build step required.

1. Clone or download this repository.
2. Open the `index.html` file in your web browser.
3. Use the navigation bar to start analyzing your statistical data!
